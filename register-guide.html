Google Search Console 등록
구글 검색 결과 노출 · 크롤링 관리 · 색인 현황 확인
→ 콘솔 열기
💡
사이트가 https://xn--bn1bl1opra.kr 에 배포된 후에 진행하세요. 로컬 개발 서버에서는 인증이 완료되지 않습니다.
1
Google Search Console 접속 · 로그인
https://search.google.com/search-console 접속 후 구글 계정으로 로그인합니다.
2
속성 추가 → URL 접두어 방식 선택
"속성 추가" 클릭 → "URL 접두어" 선택 → 아래 URL 입력:
https://xn--bn1bl1opra.kr/
3
HTML 태그 방식으로 인증
확인 방법에서 "HTML 태그" 선택 → 발급된 코드를 복사합니다.
예시: abc123def456ghi789
4
index.html 수정 — 인증 메타태그 활성화
index.html 51번줄 주석을 해제하고 코드를 교체합니다:
<!-- 수정 전 (주석 처리됨) -->
<!-- <meta name="google-site-verification" content="YOUR_GOOGLE_VERIFICATION_CODE"> -->

<!-- 수정 후 (주석 해제 + 실제 코드 입력) -->
<meta name="google-site-verification" content="여기에_발급받은_코드_입력">
5
배포 후 "확인" 클릭 → Sitemap 제출
수정된 사이트를 배포한 뒤 Search Console에서 "확인" 클릭.
인증 완료 후 Sitemaps 메뉴에서 아래 URL을 제출합니다:
https://xn--bn1bl1opra.kr/sitemap.xml

Android Play Store 등록 (TWA 방식)
PWA를 Android 앱으로 변환 → Play Store 배포
→ Play Console
ℹ️
TWA (Trusted Web Activity) — 별도 앱 개발 없이 PWA를 Android 앱으로 감싸 Play Store에 등록하는 방식. Google이 공식 권장합니다.
1
Google Play Console 계정 생성
play.google.com/console → 개발자 계정 등록 (1회 $25 USD 수수료)
2
Bubblewrap CLI 설치 (로컬 PC)
Android Studio + Node.js 설치 후:
npm install -g @bubblewrap/cli
bubblewrap init --manifest https://xn--bn1bl1opra.kr/manifest.json
3
twa-manifest.json 설정값
Bubblewrap 초기화 시 아래 값 입력:
Application ID: kr.co.atomia.richhouse
App Name: OK복덕방
Start URL: https://xn--bn1bl1opra.kr/
Theme Color: #14213D
Background: #14213D
4
APK 빌드 · 서명 키 생성
bubblewrap build
# app-release-signed.apk 파일 생성됨
5
SHA-256 지문 확인 → assetlinks.json 업데이트
빌드 후 생성된 SHA-256 지문을 .well-known/assetlinks.json에 입력:
# 지문 확인 명령:
keytool -list -v -keystore android.keystore

# .well-known/assetlinks.json 수정:
"sha256_cert_fingerprints": [
  "AA:BB:CC:DD:...:실제_지문"
]
6
Play Console에서 앱 등록 → 심사 제출
Play Console → 앱 만들기 → APK 업로드 → 스크린샷 등록 → 심사 제출
심사 기간: 보통 1~3 영업일
